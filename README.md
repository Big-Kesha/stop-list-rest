# Стоп-лист кухни

Тестовое задание: панель стоп-листа для менеджера зала. Один экран, где видно
меню смены, можно фильтровать по цеху и статусу, ставить позиции в стоп-лист
и снимать со стопа.

Бэкенд имитирован route handlers Next.js, данные — in-memory.

# запуск node 24

- npm install

- npm run dev

- [localhost:3000](http://localhost:3000)
